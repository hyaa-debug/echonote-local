# EchoNote Local — 你的本地语音笔记工作室

这个版本为 Windows 10/11 x64、16GB 内存电脑准备。它在你的电脑上启动一个本地网站，无需注册账号。

## 第一次使用

1. 将整个 ZIP **解压到一个文件夹**，例如 `D:\EchoNoteLocal`。不要在压缩包里直接双击运行。
2. 双击 `START.cmd`。包里已包含独立 Python 3.12 和 Windows 音频依赖，不使用或修改你已经安装的 Python。
3. 如果电脑缺少 Microsoft 运行库，启动程序会提示安装。如果没有 Ollama，会打开官方安装器，按提示完成即可。首次安装和下载期间需要联网。
4. 浏览器会自动打开本地工作室。可以先导入 `samples/chinese-demo.mp3`，这是随包附带的合成测试录音。
5. 文件导入后会依次下载缺少的模型、转写并总结。语音模型 small 约 500 MB，AI 模型 Qwen2.5 3B 约 2 GB；Ollama 安装本身还需要额外空间。建议准备 10 GB 以上可用磁盘空间。下载速度取决于网络。

首次准备要花时间，但不用手动安装 Python、FFmpeg、Node.js，不需要填 API Key。请等页面出现完成结果，不要反复导入同一个文件。

## 以后每天怎么用

**双击 START.cmd → 导入录音或视频 → 等自动整理完成。**

- 可以批量选多个文件，程序会按顺序处理，降低同时占用内存的压力。
- 选择通用笔记、会议纪要、学习笔记或面试复盘，录音语言可自动识别。
- 录音转成带时间戳的原文；点击时间戳可以跳到对应位置回听（播放能力取决于浏览器支持的格式）。
- 自动生成 AI 摘要、关键信息、待办和待确认事项；待办的负责人、截止表述只保留能在原文中找到的内容。
- 可以继续对当前记录提问、编辑原文、导出 Markdown / TXT / SRT 字幕。
- 可以关掉浏览器标签，后台会继续工作；**不要关闭启动程序的终端窗口，也不要让电脑休眠**。
- 下次打开，记录还在。重新启动时，未完成任务会标明“上次未完成”，可点击重试，不会假装已经完成。

## 文件放在哪里

录音、文字、摘要和历史对话都保存在程序旁的 `data` 文件夹。模型下载到 `data/models` 和 Ollama 自己的模型目录。

备份时先关闭启动窗口，再复制整个 `data` 文件夹。换文件夹时移动整个应用文件夹即可；Ollama 的模型不在应用文件夹里，换电脑仍需准备。Windows Ollama 模型通常位于用户目录的 `.ollama/models`，如有自定义，以 Ollama 配置为准。

清理浏览器缓存不会清掉这些笔记。程序没有自动删除历史记录或录音的功能，避免误删；需要释放空间时先做好整个 data 的备份。

## 网络与隐私

- 本程序只监听 `127.0.0.1`，不向局域网或公网开放网站。
- 语音与总结模型准备完成后，本地文件处理不需要联网，不收取 API 调用费用。
- 音频转写在 faster-whisper 中执行；总结和问答只访问本机 Ollama，不把录音或正文发送到云端 API。
- 首次环境或模型准备会访问 Python、PyPI、Microsoft、Hugging Face、Ollama 官方服务；模型下载失败时，先确认网络可达，之后重试即可。
- 当前程序不会上传你的录音和笔记，但外部组件自身的更新检查等行为由其各自设置控制。

## 如果有问题

- **出现 Ollama 安装窗口：** 完成安装，然后继续等待本地网页打开。
- **已经转写，但总结没完成：** 原文和录音会保留。双击 `PREPARE_AI.cmd`，完成后回到记录点“重新总结”。
- **模型下载失败：** 检查网络能否连接 Hugging Face 和 Ollama，再点设置里的“下载 / 检查本地模型”；下载通常会复用已有部分。
- **网页打不开：** 双击 `START.cmd`；查看终端显示的本地地址。端口被占用时程序会尝试后面的空闲端口。
- **页面提示已过期：** 程序重启后刷新网页即可。
- **第一次加载慢：** 这是 CPU 本地模型运行，时间取决于 CPU 和录音长度。不会用固定的“30秒完成”等承诺误导你。
- **更换转写模型：** 关闭程序，在 `data/config.json` 中设置 `{"asr_model":"base","ai_model":"qwen2.5:3b"}` 可换成更小的 base 模型；中文效果与 small 不同，首次需下载新模型。一般无需改动默认值。
- 错误日志在 `data/logs/app.log`；启动安装日志在 `data/logs/setup.log`。日志可能包含文件标题或错误详情，对外发送前自行检查。

## 当前边界

本版支持本地音频与视频文件、文字导入。暂不支持视频平台链接抓取、说话人分离、云端同步或在手机上直接访问电脑服务。

单个文件限制 2GB。未对任意超长视频做保证。长记录通过分段总结再合并，模型仍可能遗漏细节，重要内容需要回看原文。编辑原文后会清除旧摘要、问答和时间戳，避免它们与新原文不一致。

Windows 启动器已做语法检查，Windows 依赖的二进制包已下载并检查依赖完整性；开发与实际模型测试在 Linux 进行，不能替代在你的 Windows 电脑上首次运行的验证。请参阅 `VALIDATION.md`。

## 源码说明

应用代码位于 `app`，`run.py` 是本地入口。`requirements.txt` 固定核心依赖，`requirements-lock-windows.txt` 记录随包的 Windows 完整依赖版本。`tests` 包含队列、保存、失败恢复、导出、接口来源检查等测试。

源码为本次定制交付，第三方运行时和依赖保留各自版权及许可证。有关第三方组件见 `THIRD_PARTY.md`。


## 兼容性更新
已修正 Windows 上缺少 pkg_resources 的问题：私有运行环境锁定 setuptools 80.9.0，随包提供离线兼容轮子；启动器会区分 Python 模块缺失与 DLL 运行库问题。原有下载链接对应的完整包已更新。已安装旧包的电脑可以使用 EchoNote-PkgResources-Repair.zip 小补丁，不必重新下载完整包。
